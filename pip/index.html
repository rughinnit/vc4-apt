VideoCore IV wheels

Pure-Python packages for the VideoCore IV QPU stack. The engine library (libvc4infer.so.1) and the daemon come from the apt repository.

  • torch_vc4-0.3.0-cp313-cp313-linux_aarch64.whl
  • torch_vc4-0.3.1-cp313-cp313-linux_aarch64.whl
  • vc4infer-1.2.10-py3-none-any.whl

Install

sudo apt install vc4-toolkit          # the whole stack
pip install --extra-index-url https://rughinnit.github.io/vc4-apt/pip/simple/ vc4infer
pip install --extra-index-url https://rughinnit.github.io/vc4-apt/pip/simple/ torch-vc4

Projects: torch-vc4, vc4infer
