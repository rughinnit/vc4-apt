vc4infer — VC4 inference engine for Raspberry Pi

PEP 503 index. Install:

pip install --extra-index-url https://rughinnit.github.io/vc4-apt/pip/simple/ vc4infer
  • vc4infer

The client is pure Python (ctypes) and requires the matching libvc4infer.so.1, shipped by apt install vc4infer from the vc4-apt repository.
